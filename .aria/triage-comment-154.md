### Deviation Note

**偏离 1 —— 根因归属错误(影响修复设计)**

issue 根因第 3 点称「Shebang 声明了 bash,但 hook runner 使用 `$SHELL` (zsh) 执行 command 模式的 hooks」。实测不成立:

- `hooks/hooks.json` 在报告版本 **v1.47.0(commit `05091ea`)** 与当前 **v1.55.0** 均为
  `bash ${CLAUDE_PLUGIN_ROOT}/hooks/secret-guard.sh` —— **显式以 `bash` 执行**,zsh 从不解释该脚本。
- 报错格式 `script: line N: cmd: command not found` 是 **bash** 的;zsh 的格式是 `script:N: command not found: cmd`。issue 贴出的正是 bash 格式。

**真实根因**:macOS 自带 `/bin/bash` 停留在 **3.2**(Apple 因 GPLv3 不升级),而 `readarray` / `mapfile` 是 **bash 4.0** 引入的内建。

**后果**:issue 提议的两个修复中,「让 hook runner 尊重 shebang」是 **no-op**(已经在用 bash 了)。唯一有效方向是第一个,但需保留 `| tr -d '\r'`(#132 CRLF 防护),不能简单替换。

**偏离 2 —— 自报版本不可信(且本身是一个独立缺陷)**

`aria-report/SKILL.md:59` 用
`cat "${CLAUDE_PLUGIN_ROOT}/VERSION" | grep -m1 '^[0-9]'`
抽版本号。但 `VERSION` 的版本行是 `> **版本**: 1.55.0`(不以数字开头),该 grep 反而命中 **`VERSION` 第 40 行** —— 一个围栏代码块内的冻结示例串 `1.47.0`。

逐字复刻该命令实测:

| 安装 | plugin.json | aria-report 抽出 |
|---|---|---|
| cache/1.50.1 | 1.50.1 | **1.47.0** |

| cache/1.53.0 | 1.53.0 | **1.47.0** |

即 **所有 aria-report 生成的 issue,环境信息段的插件版本都是错的**。这同时解释了 #156 与 #152 的同款「1.47.0」。建议单独立 issue。
