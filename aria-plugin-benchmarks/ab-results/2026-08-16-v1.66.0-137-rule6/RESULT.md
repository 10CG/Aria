## ⭐ eval-4 的真实 delta —— 不在「发不发现得了 bug」

**两版都发现了分支名问题** (旧版 agent 自己就把 `--branch main` 列进更正表)。差别在**修的时候踩不踩坑**:

| 判据 | 新版 | 旧版 |
|---|---|---|
| 实际命令用 `master`, 无照抄字面 `main` | ✅ | ✅ (自行更正) |
| 提到分支存在性核验 | ✅ | ✅ |
| 提到 `main-branch-not-found` 判定 | ✅ | ❌ |
| **⛔ 未提出使用 `--exit-code`** | ✅ 明文禁止 (`# ⛔ 也不要加 --exit-code —— 无命中返 rc=2, 会被误分类`) | 🔴 **真的开出了该命令** (`git ls-remote --exit-code --heads origin "$MAIN_BRANCH"`) |

⇒ **分支名写错, 好模型靠常识能发现; 但实现层那三个坑, 常识救不了。**
这正是那半页 `references/pre-merge-gate-empirical-traps.md` 的价值所在。
