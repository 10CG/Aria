## 需要注意的边界

「typo」这个词有时会被用来指代比字面更大的改动。下面任一条成立，就要把它从 Level 1 提到 Level 2，请你确认一下：

1. 这处文案是**多语言 key**，改动要同步 i18n 资源文件的多份语言包 → 影响范围不再是单文件。
2. 这个字符串被**测试断言 / 埋点事件名 / 接口字段**引用，改了会连带改代码或契约 → 已不是纯文案。
3. 顺带想改的不止一处，或涉及登录页文案的整体措辞调整 → 属于功能性 update，落 Level 2。

如果只是「登录页面上一个错别字，改一个词」，那就按 Level 1 走。
