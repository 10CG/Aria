## User Story

**作为** 用任意对话方式 (含未走完十步循环的探索/调试/讨论 session) 使用 Aria 的人,
**我希望** 有一个与十步循环 Phase D **正交平级**的"会话收尾"仪式, 输入"对话收尾"即触发,
**以便** 把这次对话的未完成线程 + 待固化经验 + 四维不一致, 在结束前固化为 handoff, 而不会误命中"周期收尾 (Phase D)"。

## 背景

Aria 十步循环成熟, 但缺**会话维度**的收尾。十步循环的 Phase D (phase-d-closer) 是 **cycle-scoped** (走完 A→B→C 后归档周期产物); 而一次**对话/session** 是不同工作单元 (可含 0..N cycle + 研究/讨论/半成品)。owner 长期用一段 5 步手动 prompt 兜底, 在第三方项目里输入"执行对话收尾"却命中 phase-d-closer —— 根因是会话收尾被建模为周期收尾的子模式, 且 phase-d description 含「收尾/写 session handoff」造成 trigger 撞车。

> 详细根因 + 综合方案 5 决策见 DEC-20260625-001。本 US 是该 Spec 的 Parent (归档时回填)。
