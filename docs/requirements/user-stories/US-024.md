## User Story

> **作为** Aria 2.0 方法论实施者,
> **我希望** 在 US-023 M3 完整 cycle (S0→S9_CLOSE) + 双 provider HA + crash recovery 基础上, 接入人类审批 gate (S7_HUMAN_GATE), 通过 Feishu 卡片通知 + Forgejo PR 评论决策 (`/aria approve` / `/aria reject: <reason>`),并实现 7d ack auto-reject + reject_reason 持久化 + dispatch_id 单一幂等键,
> **以便** 让 AI dispatch 的 PR 必须经 owner 显式批准才能合并, 满足 PRD §32 "人类只在关键节点审批" 的 v2.0 核心安全语义, 并为 M5 review-loop / 防漂移 / 审计日志 immutable 提供数据基座 (reject_reason 持久化即是 M5 训练样本)。

| **A** | Feishu 审批 SLO | `median(decision_at - human_gate_entered_at) < 10min` over N≥5 real-or-synthetic dispatches |
| **B** | 7d auto-reject 验证 | Tier-1 fake-cycle test: AdvancingClock 推进 7d → outcome=S_FAIL(human_timeout) + Feishu 二次告警 sent + dispatches.db `fail_reason='human_timeout'` |
