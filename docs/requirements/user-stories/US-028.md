## 简介

US-028 是 Aria 2.0 **M7 — aria-fleet 落地** (参考实现层)。aria-fleet 把 v1.x/v2.0 的单项目能力扩展为**跨项目"指挥塔"**: 让 Layer 1 主管 (Hermes) 跨所有 10CG 项目聚合状态、复用/分发 agent。

经 2026-05-27 brainstorm (D1-D6 Approved) 确立三层架构 + 命名 + 时机; 2026-06-18 双 brainstorm ("先 1 再 2") 收敛两个子能力的 MVP 第一刀:

1. **fleet 跨项目只读聚合** (`aria-2.0-m7-fleet-aggregation`): 聚合各项目 `state-snapshot.json` → `fleet_status/project/blocked` 接口回答"哪个项目卡了"。只读, 复用 state-scanner 产物。
2. **agent 生命周期管理** (`aria-2.0-m7-agent-lifecycle`): git 集合库 + 按项目特征推荐 + 物化进 `.claude/agents/` + lockfile + 更新-基础版 (下行 pull 半环; 上行 ⑤吸收⑥汇总/AB/活体库 DEFERRED M7+)。

**定位** (D1 #1): 对内通用 — L1 代码写成 any-org 通用 (零 10CG hardcode), 当前只 10CG workspace 实例用, 不对外发布。
