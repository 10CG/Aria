## 2. 方向裁定: **先修 bug**

**解锁的理由是 owner 自己在 DEC-001 `B1` 上用过的那条, AI 当时没想到它同样适用于 Spec A**:

- **版本档** (PATCH / MINOR / MAJOR) **只在发版那一刻承重** —— 它不改变这三处代码怎么写;
- **Level 档**确实前置于开发 (Level 3 要多一份 `tasks.md`);
- ⇒ **按 Level 3 走 Spec A** (多写一份 tasks.md, Level 3 天然包含 Level 2 的交付面, 不欠交付),
  **版本档留到发版前再定**。

⇒ **Spec A 立刻解冻。** DEC-20260813-001 的前置「定档规则书」change **照做, 但它挡的是发版, 不是写代码**。

⚠️ **AI 判断留痕 (Rule #10)**: 「版本只在发版承重」是 **AI 的解释**, 不是 SOT 逐字 ——
十步循环规定 Phase A 走完才进 Phase B, 而「版本档未定算不算 Phase A 没走完」规范里没写。**请复议。**
